# Tab Out

**[English](README.md) | [中文](README_CN.md)**

**掌控你的标签页。**

Tab Out 是一个 Chrome 扩展，用一个清爽的仪表盘替换你的新标签页，一眼看到所有打开的标签。标签按域名自动分组，首页类标签（Gmail、X、LinkedIn 等）独立归类。关闭标签时有酷炫的音效和彩纸动画。

无需服务器、无需账号、无需任何外部请求。纯本地 Chrome 扩展。

## 功能列表

### 标签管理
- **一览所有标签** — 按域名分组的卡片网格布局
- **首页归类** — Gmail 收件箱、X 主页、YouTube、LinkedIn、GitHub 首页自动归入一组
- **酷炫关闭** — 关闭标签时有音效 + 彩纸爆破动画
- **重复检测** — 标记相同页面的重复标签，一键去重
- **点击跳转** — 点击标签标题直接切换到对应窗口，不会新开标签
- **批量关闭** — 可按域名组关闭，也可一键关闭所有标签
- **Localhost 分组** — 在标签旁显示端口号，轻松区分不同本地项目
- **可展开分组** — 默认显示前 8 个标签，"+N more" 按钮展开其余
- **智能标题** — 自动清理标签标题中的通知数、邮箱地址和冗余站点名

### 稍后阅读
- **收藏标签到待办清单** — 关闭前一键保存
- **勾选完成** — 已读项目移入可搜索的归档区
- **一键删除** — 移除不再需要的项目
- 数据通过 `chrome.storage.local` 持久保存，跨会话不丢失

### 搜索栏
- **集成搜索** — 支持 Google、Bing、百度，一键切换
- **实时联想** — 输入时自动获取搜索建议
- 搜索结果在新标签页打开

### 快捷方式
- **可编辑的快捷方式网格** — 类似 Chrome 默认新标签页的快捷入口
- 支持添加、编辑、删除常用网站
- 本地存储，无需同步

### 实用面板（右侧栏）
- **最近关闭** — 查看刚关闭的标签，一键恢复（基于 `chrome.sessions`）
- **标签统计** — 总标签数、域名数、重复数、Top 5 域名分布条形图
- **专注计时器** — 25 分钟番茄钟，支持开始/暂停/重置，完成时有提示音
- **快速笔记** — 自动保存的便签本（存储在 `chrome.storage.local`）

### 外观
- **深色 / 浅色 / 跟随系统** — 三档主题切换，即时生效
- 防闪烁机制 — 深色模式下打开新标签不会出现白色闪屏
- **实时时钟** — 头部显示日期和时间（24 小时制，精确到秒）

### 通用
- **三栏布局** — 适配宽屏显示器：左侧收藏栏、中间标签区、右侧实用面板
- **响应式** — 窄屏（< 1100px）自动堆叠为单列
- **100% 本地** — 数据不会离开你的设备
- **纯 Chrome 扩展** — 无需服务器、Node.js、npm，加载扩展即可使用

## 手动安装

**1. 克隆仓库**

```bash
git clone https://github.com/zarazhangrui/tab-out.git
```

**2. 加载 Chrome 扩展**

1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择克隆下来的仓库中的 `extension/` 文件夹

**3. 打开新标签页**

你会看到 Tab Out。

## 工作原理

```
打开新标签页
  -> Tab Out 按域名分组展示你的所有标签
  -> 首页类标签（Gmail、X 等）独立分组置顶
  -> 点击标签标题直接跳转
  -> 关闭不需要的分组（音效 + 彩纸动画）
  -> 关闭前可将标签保存到"稍后阅读"
```

所有功能都在 Chrome 扩展内运行。没有外部服务器、没有 API 调用、数据不会发送到任何地方。保存的标签存储在 `chrome.storage.local` 中。

## 技术栈

| 项目 | 实现方式 |
|------|----------|
| 扩展框架 | Chrome Manifest V3 |
| 数据存储 | chrome.storage.local（主题、快捷方式、笔记、收藏标签、搜索引擎偏好） |
| 会话管理 | chrome.sessions API（最近关闭的标签） |
| 音效 | Web Audio API（合成音效，无音频文件） |
| 动画 | CSS transitions + JS 彩纸粒子 |
| 搜索建议 | 通过 Service Worker 代理请求绕过 CORS（Google、Bing、百度） |
| 主题系统 | CSS 自定义属性 + `data-theme` 属性，支持系统偏好检测 |
